# Skill-and-You-maquetter-des-interfaces-utilisateur-web-ou-web-mobile

Exercice : CV Bootstrap 📝

Ce projet a pour objectif de présenter ma vitrine professionnelle claire, moderne et responsive. Il intègre une navigation bilingue ainsi qu'un système d'onglets dynamiques pour consulter facilement mon parcours académique, mes expériences professionnelles, mes réalisations et mes compétences techniques.

🚀 Fonctionnalités :
Bilingue (FR / EN) : basculement fluide entre la version française (cv-fr.html) et la version anglaise (cv-en.html).
Design Responsive : adaptation optimale aux écrans mobiles, tablettes et ordinateurs grâce à Bootstrap 5.
Navigation par onglets (pills) : organisation dynamique des contenus (formations, expériences, projets, compétences) sans rechargement de page.
Palette de couleurs sur mesure : thème personnalisé axé sur des tons verts apaisants et naturels (sauge, vert forêt, lin).
Intégration d'icônes techniques : utilisation de Devicon et Bootstrap Icons pour un rendu visuel moderne.

🛠️ Technologies utilisées :
HTML5 : structure sémantique du site.
CSS3 : styles personnalisés, variables CSS et ajustements visuels.
Bootstrap 5.3.3 : framework CSS pour la grille responsive et les composants (navigation, onglets, cartes).
Bootstrap Icons et Devicon : bibliothèques d'icônes professionnelles et de logos informatiques.
